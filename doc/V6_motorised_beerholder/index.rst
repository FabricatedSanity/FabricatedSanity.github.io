Motorised V6 engine block for holding beverages
===============================================

This project was based on `3DMakerSpace <https://makerworld.com/en/models/2398784-v6-engine-beer-display-with-rotating-crankshaft?from=search#profileId-2629024>`_
It have been modified to be motorised and to fit a 0.5L beer can. The crankshaft is connected to a motor, which allows the engine block to rotate and display the beverage in a dynamic way.
It's also made to include cooling with tubes for water circulation inside the cylinder holders, and a small pump to circulate the water.
The holes in the side of the engine block where used to place LEDs inside the block to make it light up.
